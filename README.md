## Project Structure

* `src/` — Contains the Python source code for the security scanner.
* `reports/report.json` — Contains a sample JSON security assessment report.
* `docs/` — Contains project documentation, including the OWASP Top 10 summary, lab setup instructions and reconnaissance notes.
* `requirements.txt` — Lists the project's Python dependencies.
* `README.md` — Describes the project, installation and usage.

## Running the Scanner

 To run the python code first open the folder then go to the terminal in your visual studio code and type "python src/scanner.py"
